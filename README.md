# BrewHouse Coffee ☕

A responsive, single-page website for a **fictional** coffee shop. Created as a frontend portfolio demonstration.

## Features
- Mobile-friendly responsive layout
- Accessible mobile navigation
- Coffee menu with sample prices
- Contact form with client-side validation (**demo only; does not send messages**)
- Semantic HTML and CSS Grid

## Technologies
HTML5, CSS3, vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code's Live Server extension.

## Deployment
Push the project to a public GitHub repository, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## Important
The café, location, hours, and menu are fictional. Photos are externally loaded from Unsplash and require an internet connection. Verify image licensing/usage terms before commercial reuse.
